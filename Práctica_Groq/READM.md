## README

Este notebook demuestra varias funcionalidades de la API de Groq, incluyendo:

- **Clasificación de Sentimientos**: Usando un LLM para clasificar sentimientos en texto.
- **Generación de Texto**: Generando texto basado en diferentes prompts.
- **Resumen Automático de Texto**: Resumiendo texto usando tanto un LLM como un modelo BART preentrenado.
- **Ingeniería de Prompts**: Experimentando con diferentes estructuras de prompts para observar su impacto en las respuestas del LLM.
- **Análisis Crítico**: Explorando posibles sesgos, alucinaciones y consideraciones éticas de los LLMs.

### Configuración

Asegúrate de tener las librerías necesarias instaladas:

```bash
pip install groq transformers torch pandas numpy matplotlib
```

Y configura tu clave de API de Groq.
